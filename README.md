# SERIES-HUB
A cinematic web platform for exploring 8 popular English web series, featuring individual series pages, ratings, descriptions, trailers, and an interactive Watch Now popup.
 SeriesHub – Explore the World of Web Series

SeriesHub is a cinematic web platform designed to help users explore popular English web series, discover series information, view ratings, and access trailers through a visually engaging interface.

 Project Overview

SeriesHub provides a simple and interactive browsing experience with a dark-themed design inspired by modern streaming platforms.

✨ Features

-  Interactive Homepage – Displays 8 popular English web series.
- ️ Series Posters – Visual cards with attractive series images.
-  Individual Series Pages – Dedicated pages containing series information and descriptions.
- ⭐ Ratings – Displays series ratings.
- ️ Trailers Section – Explore trailers through YouTube links.
- ▶️ Watch Now Option – Includes a subscription popup.
-  Easy Navigation – Navigate between homepage, series pages, and trailers.
-  Dark Cinematic Theme – Modern streaming-platform-inspired interface.
